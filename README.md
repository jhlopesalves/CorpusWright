CorpusWright is a local-first desktop workbench for preparing, analysing, and exploring text corpora.

It imports PDF, DOCX, HTML, and plain-text sources; keeps extraction and cleaning visible; builds a reproducible corpus; and runs its analysis locally on your machine.

## Status

CorpusWright is an experimental alpha.

The preparation workflow and the first analysis and exploration tools are usable, but the application is still changing quickly. Expect rough edges and possible project-format changes between alpha releases.

Developer setup, testing, and repository checks are documented in
[`docs/contributing/testing.md`](README.md).
