    CorpusWright

    A free and open-source desktop workbench for preparing, cleaning, inspecting, and exporting text corpora.

    Version: 0.1.0-alpha.6

    Created and maintained by: Jhonatan H. Lopes

    Contact: jhlopesalves@gmail.com

    Repository: https://github.com/jhlopesalves/corpuswright

    Released as free and open-source software under the MIT License.

    This is experimental alpha software. Please report issues through the GitHub repository.

    Import Sources

    CorpusWright inspected the selected files. Importing registers them in the project and stores how PDFs should be handled. Text extraction/OCR and cleaning are separate steps.

      Cleaning Settings

      These cleaning settings affect processed previews and exported text. Source files are never modified.

      Basic Cleaning
      Encoding

      Removes only lines that look overwhelmingly like extraction artefacts, OCR junk, repeated symbols, CID markers, or markup fragments. It does not remove headings, page labels, formulae, tables, or ordinary text.

      HTML Extraction

      HTML files are extracted to readable plain text before normal cleaning is applied. Strips tags, decodes entities, and preserves spacing.

      Table Extraction Strategy

      Defines how tabular data (e.g., DOCX tables) should be transformed into plain text.

      Default PDF import policy

      Used as a fallback for older sources and for new PDF sources without a source-level route. The Import Sources dialog stores the route for each imported source.

      Default OCR quality for new PDF sources

      Used by PDF routes that run OCR when no source-level OCR quality has been stored.

      PDF Embedded Text Strategy

      Controls how raw PDF text is reconstructed from the character stream. Reload preview after changing.

      DOCX Extraction
      PDF Cleanup

      PDF cleanup options are conservative and apply only to PDF-derived text. These options may remove meaningful programming, statistical, or mathematical examples. Inspect processed preview before export.
