# OCR model provenance

The bundled `text-detection.rten` and `text-recognition.rten` files are the default pre-trained model artefacts published for `ocrs` 0.12.2 (`ocrs-v0.12.2`, commit `2dbc1f840e47d45630ef6060499138bf597a9f65`).

Both repository files byte-match the authoritative model URLs used by that tagged release. Their source URLs, S3 version identifiers, ETags, sizes, SHA-256 checksums, training-source refs, and model-card ref are recorded in `third-party/ocr-models.json`.

The model card licenses the pre-trained weights under CC BY-SA 4.0 and attributes training to HierText and synthetic data. Redistribution requires attribution and compliance with the licence's ShareAlike terms.
