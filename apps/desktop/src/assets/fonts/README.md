# Bundled Fonts

These files back the fixed Appearance font shortlist. System UI remains the default and is not bundled.

Bundled UI and reading faces:

- Inter: `InterVariable.woff2`, SIL OFL 1.1, from https://github.com/rsms/inter
- IBM Plex Sans: regular, medium, semibold, and bold WOFF2 files, SIL OFL 1.1, from https://github.com/IBM/plex
- Roboto: `Roboto.ttf`, SIL OFL 1.1, from https://github.com/google/fonts/tree/main/ofl/roboto
- Noto Sans: `NotoSans.ttf`, SIL OFL 1.1, from https://github.com/google/fonts/tree/main/ofl/notosans
- Fira Sans: regular, medium, semibold, and bold TTF files, SIL OFL 1.1, from https://github.com/google/fonts/tree/main/ofl/firasans
- Open Sans: `OpenSans.ttf`, SIL OFL 1.1, from https://github.com/google/fonts/tree/main/ofl/opensans
- Atkinson Hyperlegible: regular and bold TTF files, SIL OFL 1.1, from https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible
- Lexend: `Lexend.ttf`, SIL OFL 1.1, from https://github.com/google/fonts/tree/main/ofl/lexend
- Source Sans 3: `SourceSans3VF-Upright.otf.woff2`, SIL OFL 1.1, from https://github.com/adobe-fonts/source-sans
- Source Serif 4: `SourceSerif4Variable-Roman.ttf.woff2`, SIL OFL 1.1, from https://github.com/adobe-fonts/source-serif
- Noto Serif: `NotoSerif.ttf`, SIL OFL 1.1, from https://github.com/google/fonts/tree/main/ofl/notoserif
- Literata: `Literata.ttf`, SIL OFL 1.1, from https://github.com/google/fonts/tree/main/ofl/literata
- Gentium Plus: regular, semibold, and bold WOFF2 files, SIL OFL 1.1, from https://software.sil.org/gentium/
- Charis SIL: regular and bold TTF files, SIL OFL 1.1, from https://github.com/google/fonts/tree/main/ofl/charissil

Bundled mono faces:

- JetBrains Mono: regular and bold WOFF2 files, SIL OFL 1.1, from https://github.com/JetBrains/JetBrainsMono
- Fira Code: `FiraCode.ttf`, SIL OFL 1.1, from https://github.com/google/fonts/tree/main/ofl/firacode

The files are kept as upstream font builds rather than aggressively subset. That preserves the Latin, Latin Extended, IPA, and combining-diacritic coverage needed for concordance and linguistic review text.
