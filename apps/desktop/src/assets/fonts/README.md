# Bundled font provenance

The application and website fonts are unmodified upstream builds licensed under the SIL Open Font License 1.1.

The per-file source path, immutable upstream commit or release, SHA-256, and applicable licence file are recorded in `third-party/fonts.json`. Upstream licence texts, including copyright and Reserved Font Name notices, are retained under `third-party/fonts/licenses/`.

The recorded sources are Google Fonts, Inter, IBM Plex, JetBrains Mono, Adobe Source Sans, Adobe Source Serif, and SIL Gentium. Gentium is release 7.000; Source Serif is release 4.005R. The manifest pins the exact revisions used for every other source.
