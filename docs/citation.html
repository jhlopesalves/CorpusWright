Citation examples for CorpusWright

These examples follow the current citation metadata. Cite the specific version you used; About gives the citation guidance and template.

Preferred citation format (APA)

Cite the software directly, naming the specific version you used. For example:

Lopes, J. H. (2026). CorpusWright (Version 0.1.0-alpha.8) [Computer software]. https://github.com/jhlopesalves/CorpusWright

BibTeX template

For LaTeX, Pandoc, or reference managers, you can adapt the template below:

@software{lopes_corpuswright_2026,
  author  = {Lopes, Jhonatan H.},
  title   = {CorpusWright},
  year    = {2026},
  version = {0.1.0-alpha.8},
  url     = {https://github.com/jhlopesalves/CorpusWright},
  note    = {ORCID: 0009-0008-4914-0262}
}

Machine-readable CITATION.cff

The authoritative machine-readable citation record is the repository's CITATION.cff. The examples above follow that metadata.

GitHub citation support

GitHub reads the repository's CITATION.cff when it presents citation information. Check the version in that record against the version of CorpusWright you used.
