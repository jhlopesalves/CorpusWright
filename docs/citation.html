Citation Guidance

Citing CorpusWright in research and teaching

CorpusWright is open-source research software. If it helps you compile, preprocess, or clean your text corpora for publications, studies, or presentations, please cite the specific version you used.

Preferred citation format (APA)

Cite the software directly, naming the specific version you used. For example:

Lopes, J. H. (2026). CorpusWright (Version 0.1.0-alpha.8) [Computer software]. https://github.com/jhlopesalves/CorpusWright

BibTeX template

For LaTeX, Pandoc, or reference managers, you can adapt the template below:

@software{lopes_corpuswright_2026,
  author  = {Lopes, Jhonatan Henrique},
  title   = {CorpusWright},
  year    = {2026},
  version = {0.1.0-alpha.8},
  url     = {https://github.com/jhlopesalves/CorpusWright},
  note    = {ORCID: 0009-0008-4914-0262}
}

Automatic extraction from GitHub

The repository carries a machine-readable CITATION.cff metadata file. On the right-hand sidebar of the CorpusWright GitHub page, you can click the “Cite this repository” button to copy the APA citation or export the BibTeX block directly. This widget will always match the latest release's metadata.

Version-specific DOI (via Zenodo)

When permanent DOIs (e.g. Zenodo) are minted for official releases, citing the version-specific DOI is preferred to referencing the repository URL. This guarantees that your research references the exact software build, ensuring the reproducibility of your preprocessing pipeline.
