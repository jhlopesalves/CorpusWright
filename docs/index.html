Local-first corpus workbench

Clean, inspect, and analyse corpora without surrendering your texts.

CorpusWright is a desktop tool for corpus linguistics workflows where privacy, reproducibility, and auditability matter. It starts with careful preprocessing and grows towards statistically serious analysis.

Get started Read the method Releases

Alpha software

CorpusWright is early-stage. It is useful for testing workflows, but not yet a polished general-purpose research platform.

Expect rapid changes, rough edges, and documentation that tracks the design as it stabilises.

What it is trying to be

Local-first

Your corpus stays on your machine. CorpusWright is designed for researchers who work with private, copyrighted, classroom, or institutionally sensitive texts.

Auditable cleaning

Cleaning rules should be reviewable, deterministic, and explainable. The tool should help you inspect artefacts rather than silently invent corrections.

Analysis-aware

Preprocessing is not separate from analysis. KWIC, repeated artefact review, frequency lists, dispersion, and collocation workflows belong in the same loop.

Current focus

Preprocessing workspace

Load corpus sources, extract text, preview original and processed text, configure deterministic cleaning rules, and export processed corpora with provenance.

Repeated artefact review

Find repeated headers, footers, page labels, boilerplate, and extraction leftovers. Promote candidates into structured removal rules only after review.

Built for boringly serious research habits

CorpusWright favours explicit choices over magic, files over hidden state, local processing over cloud dependency, and transparent limitations over inflated claims.
