CorpusWright

A local-first corpus workbench.

CorpusWright is a desktop application for preparing, inspecting, and analysing research corpora. It combines source management, deterministic cleaning, corpus inspection, and analysis-oriented workflows in a Rust-based application.

Documentation Source code Releases

Overview

CorpusWright is intended for corpus linguistics work where preparation and analysis need to remain close together. The current alpha focuses on local project folders, extraction from common source formats, configurable text cleaning, processed previews, repeated-artefact detection, and early corpus-level frequency analysis.

The project is deliberately local-first: source files and processed corpora remain on the user's machine. Cleaning steps are designed to be repeatable, inspectable, and recorded rather than hidden behind irreversible preprocessing.

Project principles

These principles shape the design of the application and its analysis layer.

Local-first

Corpus files are processed on the user's machine. The application does not depend on uploading research material to a remote service.

Deterministic

The same corpus and the same cleaning configuration should produce the same processed output.

Auditable

Cleaning operations should be visible and reviewable, especially when they remove recurring headers, footers, page numbers, or extraction noise.

Analysis-aware

Corpus preparation, concordancing, annotation, frequency lists, and distributional measures belong in one workflow rather than disconnected tools.

Current status

CorpusWright is in alpha. The table below separates currently available functionality from experimental and planned work.

Area Status Notes
Local project folders Available Corpus sources and project state are stored locally.
Source extraction Available TXT, HTML, DOCX, and PDF sources are supported.
Cleaning configuration Available Includes deterministic processing options and processed-text previews.
Repeated-artefact finder Available Detects recurring corpus noise such as headers, footers, and boilerplate.
Structured custom removals Available Supports explicit removal rules for known text artefacts.
Frequency list Available Provides early corpus-level frequency inspection.
Lemma / POS annotation Experimental Annotation support is present but still being stabilised.
KWIC / concordance Planned Part of the upcoming Explore workbench.
Collocation analysis Planned Will be built on positional indexes and transparent association measures.
