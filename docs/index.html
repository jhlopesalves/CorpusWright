CORPUSWRIGHT

A local-first corpus workbench.

Build, clean, inspect, and analyse research corpora — entirely on your machine. Every cleaning step is recorded and every statistic is defined, so the results are yours to inspect and reproduce.

Download the alpha Read the docs Source code Cite

Experimental alpha (v0.1.0-alpha.7). Windows and macOS builds are unsigned, so your operating system may warn before letting them run.

Citation

If you use CorpusWright in your research or teaching, please cite it. The repository contains a machine-readable CITATION.cff file. You can easily copy APA or BibTeX citations from the “Cite this repository” widget on the GitHub repository page.

For more details and custom reference formats, see the full Citation Guidance.
