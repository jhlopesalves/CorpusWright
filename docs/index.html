A local-first corpus tool, built in Rust.

CorpusWright is a local-first desktop workbench for preparing, inspecting, and exploring text corpora, with frequency lists, KWIC concordances, collocate and document-spread views. Cleaned-corpus exports record the cleaning and tokenisation configuration.

Experimental alpha. Windows, macOS, and Linux builds are listed on the release page where available; unsigned Windows and macOS builds may prompt a warning before running.

Preparation records

Cleaned-corpus exports include a manifest with the cleaning configuration, tokeniser settings and SHA-256 checksums for the included source and processed files.

Statistical profile

The corpus overview reports frequency, diversity, dispersion, concentration and distributional-shape measures. Definitions and interpretation notes accompany the principal measures.

Transparent

The concepts guide presents formulas, interpretations and limitations for the principal reported statistics.

Built in Rust

A native Rust core performs corpus preparation and analysis on the user's machine.
