Method

CorpusWright treats cleaning as part of the analysis.

Corpus preprocessing is part of the analysis, not a preliminary stage to be set aside once the corpus is built. Every cleaning decision should be inspectable, reproducible, and connected to the points in the workflow where its effects become visible.

Deterministic by default

Cleaning rules produce the same result on every run. A saved configuration is part of the research record: it can be inspected, shared, and re-applied without relying on any recollection of manual steps taken in the interface.

Review before removal

A detected repeated artefact is evidence, not an instruction to remove it. The application identifies candidate noise but does not act on it automatically; a candidate becomes a cleaning rule only once it has been explicitly reviewed and accepted. The default is to preserve text rather than to discard it on inference alone.

Page-aware when possible

Headers and footers belong to the structure of the page rather than to the running text. Where the source format permits, CorpusWright interprets a PDF as a paged document and distinguishes page-level structure from flat-text fallbacks.

An integrated analysis loop

Assessing whether a cleaning decision was sound should not require repeated export and re-import between separate tools. Cleaning, concordance inspection, and frequency analysis are designed to operate within a single, continuous workflow.

The principles

A tool that presents numbers is not, by that fact alone, a rigorous one. The following commitments guide the design of CorpusWright:

Local-first: Private corpora should not have to be uploaded to a remote server; all analysis remains on your own machine.

Auditability: Extraction warnings and cleaning rules remain inspectable, so that preprocessing decisions can be examined and, where necessary, revised.

Conservatism: The cleaner avoids destructive inference. Where a decision is uncertain, it retains the original text rather than removing content that cannot afterwards be recovered.

Statistical restraint: Basic frequencies are reported as such, without overstatement. Analysis features are designed to respect corpus design, dispersion, document-level variation, and the uncertainty inherent in the measures.

CorpusWright is an open, local-first corpus linguistics workbench, currently in public alpha (v0.1.0-alpha.8). View the source on GitHub
