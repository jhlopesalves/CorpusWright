Getting started with CorpusWright

Install the desktop application, prepare your source texts, then inspect their counts and contexts.

Install a release build

Open the release page and choose a package for your operating system. Windows, macOS and Linux builds are listed there where available. Unsigned Windows and macOS builds may prompt a warning before running.

Download latest alpha

The public alpha is usable and still changing. Keep your original sources; expect rough edges and possible project-format changes between releases.

From source files to evidence

Prepare the text

  1. Create or open a project. Choose a project folder for its source inventory and saved settings.
  2. Add sources in Prepare. Use Add sources → Add files or Add folder, then review the Import Sources dialogue. For PDFs that need extraction, select them and use Selected actions → Extract text / OCR.
  3. Review the text and cleaning. Select a source to compare Original Text with Processed Text. Review warnings and use Cleaning Settings, Repeated Artefacts or the Custom Removals tab where needed. Check the processed preview after changing rules.

Read the corpus description

  1. Open Analyse and build the counts. Select Build surface analysis. Surface analysis uses word-form tokens rather than lemma- or POS-based annotation. Standard analysis keys are NFC-normalised and lowercased. The application uses processed text where available and reports any source-text fallback; check that input before interpreting a result.
  2. Read Corpus Overview. Select Corpus Overview in the Analysis tools rail. Check the included documents and token counts, then inspect document lengths, dispersion and vocabulary structure. Frequency List sits in the same rail and shows forms, counts, rates, range and DP.

Inspect occurrences and retain the prepared corpus

  1. Select Concordance within Analyse. Enter a word or phrase under Surface word or phrase and select Search. Read the Concordance Lines; Collocates and Distribution appear below them. Select a line to open its document context.
  2. Export the prepared text. Use File → Export Processed Corpus... to retain cleaned text, preparation settings, checksums and warnings. The top-level Export stage is marked Coming later in this alpha; the File menu provides the current cleaned-corpus export.

For definitions and interpretation, turn to Methods & measures. You can start using the application before reading the full methods reference.

Supported source formats

CorpusWright imports plain text (TXT), HTML/HTM, DOCX and PDF. PDF extraction can use embedded text or OCR; the result depends on source quality and the selected extraction route. Review the extracted text before using its counts in research.

Corpus files are processed on your computer rather than uploaded to a CorpusWright analysis service.

Building from source

A development checkout needs Rust, Node.js and the platform dependencies for Tauri. The repository holds the implementation and build tooling.

git clone https://github.com/jhlopesalves/CorpusWright.git
cd CorpusWright/apps/desktop
npm ci
npm run tauri dev
