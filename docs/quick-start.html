Basic workflow

1. Create or open a CorpusWright project.

2. Load supported source files into the preprocessing workspace.

3. Review extracted text and warnings.

4. Configure cleaning rules deliberately.

5. Preview processed text before exporting.

6. Export processed text with project metadata and warnings.

Supported source formats

The existing repository documentation describes support for TXT, HTML/HTM, DOCX, and PDF extraction, with important format-specific limitations. See the technical documentation before using CorpusWright on research-critical material.
