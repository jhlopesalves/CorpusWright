# CorpusWright v0.1.0-alpha.6

> [!NOTE]
> This release supersedes the last published alpha. The v0.1.0-alpha.4 and v0.1.0-alpha.5 releases were prepared and tagged as release candidates but were skipped/unpublished.

Theme: sortable repeated artefact candidates, improved candidate display, Windows compatibility fixes, and CI workflow corrections.

## Highlights

- Improved the repeated artefact candidate table with sortable columns and clearer long-candidate display.
- Fixed release consistency checking on Windows by making Cargo.lock version extraction robust.
- Prevented legacy CI from running on release tag pushes.

## Features

- structured custom removal rules
- normalised whole-line family rules
- page-aware document model
- cached PDF/OCR page text preservation
- page-zone scoped removal rules
- conservative page-edge candidate promotion
- deterministic candidate text/noise profiling
- opt-in obvious extraction/OCR noise cleaning
- multilingual heading/page-label heuristics
- transparent app icon packaging fix

## Bug Fixes

- Fixed diacritic-aware matching for structured custom removals when diacritic replacement is enabled.
- Fixed an issue where NFD-decomposed accents inflated symbol counts during text profiling by normalising text to NFC.
- Fixed page-zone synthetic single-page semantics to ensure page-zone rules only apply when page metadata is reliable.

## Known Limitations

- The classifier is deterministic and heuristic; it does not use a language model or model-backed classifier.
- Short or ambiguous text can remain ambiguous.
- Removed obvious-noise line counts are not yet reported.
- Page-zone rules require reliable page metadata.
- Flat text paths do not infer page zones from blank lines or file position.
- Windows may cache old desktop, Start menu, or taskbar icons after reinstall. Users who still see an old icon may need to recreate shortcuts, reinstall the app, restart Explorer, or refresh the icon cache.

## Validation

Run the release validation set before tagging:

```bash
cargo fmt
cargo clippy -p corpuswright-core --all-targets -- -D warnings
cargo clippy -p corpuswright-desktop --all-targets -- -D warnings
cargo test -p corpuswright-core -- --test-threads=1
cargo check -p corpuswright-core
cargo check -p corpuswright-desktop --all-targets
cargo run -p corpuswright-core --example export_ts
npm --prefix apps/desktop run build
node scripts/check-release-consistency.cjs
git diff --check
```

Release packaging should also run the Tauri release build used by `.github/workflows/release.yml`.
