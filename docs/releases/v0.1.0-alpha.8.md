# CorpusWright v0.1.0-alpha.8

> [!IMPORTANT]
> This is a release-note draft. Maintainer review is required before it is
> published or used to update the existing prerelease.

This prerelease supersedes v0.1.0-alpha.6, the immediately preceding public
release. The repository contains an Alpha.7 draft but no corresponding public
tag or release.

## Included changes

- Extended the Analyse workbench with corpus Overview, frequency, surface and
  phrase concordance, collocation, document-distribution, and annotation-backed
  frequency views.
- Added deterministic Overview diagnostics and a shared interactive figure
  system with SVG export and visual-contract checks.
- Added bounded, persistent Concordance indexing and demand-driven collocation
  caches, including scan/index parity auditing and recovery when index work
  fails.
- Bounded repeated-artefact scanning memory and added phase and cancellation
  reporting.
- Preserved legacy text decoding with explicit recovery and provenance.
- Split the desktop backend into command, state, service, and platform modules
  without changing the Tauri command names exposed to the frontend.
- Generated the complete frontend-facing Corpus Overview type graph from Rust.
- Pinned PDFium binary provenance and checksums for every packaged platform.

## Known limitations

- CorpusWright remains an experimental alpha; project formats and analytical
  interfaces may still change.
- Annotation-backed views require a supported project language and a completed
  local annotation-cache build.
- PDF extraction quality depends on the source PDF's embedded text and, where
  needed, the bundled PDFium and OCR resources.
- This work did not perform installer smoke tests or external validation.

## Validation required before publication

Run the repository's canonical Rust, desktop, frontend, generated-contract,
PDFium-provenance, release-consistency, and repository-reference checks. Review
the produced Windows and macOS draft artifacts manually before publishing or
replacing any public assets.
