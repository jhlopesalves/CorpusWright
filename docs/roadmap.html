Roadmap

Alpha now, research workbench later.

The first public story is preprocessing: extraction, cleaning, review, provenance, and repeatability. Analysis features should grow on top of that foundation without breaking it.

Now

  • Local project folders
  • Text extraction from supported formats
  • Cleaning settings and processed previews
  • Repeated artefact finder
  • Structured custom removals

Next

  • Sharper documentation
  • More stable release packaging
  • Better sample/demo corpora
  • Cleaner UI explanations for warnings
  • Regression-proof extraction tests

Later

  • KWIC and concordance workflows
  • Frequency and dispersion views
  • Collocates and n-grams
  • Exportable analysis artefacts
  • Statistically defensible comparison workflows
CorpusWright is an open, local-first corpus linguistics workbench, currently in public alpha (v0.1.0-alpha.7). View the source on GitHub
