Roadmap

Current alpha and planned work

The current public alpha covers preprocessing, frequency views, KWIC concordances, collocates, document-spread diagnostics, and safer text decoding. A surface positional index now exists as internal infrastructure; the next step is to route the analysis paths through it behind parity checks.

Alpha.8 now

  • Local project folders
  • Text extraction from supported formats
  • Cleaning settings and processed previews
  • Repeated artefact finder
  • Structured custom removals
  • Corpus Overview / Frequency List
  • Surface and phrase KWIC search
  • KWIC sorting and source preview
  • Document spread diagnostics
  • Collocates alpha with raw counts, corpus frequency, and logDice
  • Strict UTF-8 decoding with Windows-1252 recovery

Internal groundwork

  • Landed: surface positional index, case-sensitive parity, and an index-backed Concordance route
  • In progress: a developer-only scan, index, and audit dogfood mode that is not present in public builds

Next / near-term

  • Dogfood the current alpha on the IMDB and Portuguese corpora
  • Exercise the index-backed Concordance route against the scan engine under parity checks
  • Decide the default Concordance backend once parity holds on real corpora
  • Write the frontend Analyse workspace state-model brief
  • Shape the future single-workspace Concordance interaction model

Future

  • N-grams
  • CQL-lite
  • Lemma/POS KWIC
  • Annotation-aware Concordance
  • Richer Collocates
  • Export and copy workflows

Known alpha limits

These are the boundaries of the current public alpha.

Concordance and Collocates: functional alpha features, not the final workflow design.

Indexing: current public alpha builds still run the scan and cached analysis paths; the surface positional index is internal groundwork and is not yet the default in released builds.

Queries: there is no CQL, no N-grams, no lemma/POS KWIC, and no annotation-aware Concordance yet.

Hosting: CorpusWright is local-first. It does not provide remote corpus hosting.

Packaging: Windows builds may still show unsigned-app warnings.
