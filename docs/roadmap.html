Roadmap

Alpha workbench now, indexed analysis next.

CorpusWright alpha.8 includes preprocessing, frequency views, KWIC, collocates, document spread diagnostics, and safer text decoding. The next architecture step is the positional index that will make those analysis paths stronger.

Alpha.8 now

  • Local project folders
  • Text extraction from supported formats
  • Cleaning settings and processed previews
  • Repeated artefact finder
  • Structured custom removals
  • Corpus Overview / Frequency List
  • Surface and phrase KWIC search
  • KWIC sorting and source preview
  • Document spread diagnostics
  • Collocates alpha with raw counts, corpus frequency, and logDice
  • Strict UTF-8 decoding with Windows-1252 recovery

Next / near-term

  • Dogfood alpha.8 on IMDB and Portuguese corpora
  • Design and build the surface positional index
  • Migrate KWIC and Collocates to the index behind parity gates
  • Write the frontend Analyse workspace state-model brief
  • Shape the future one-workspace Concordance interaction model

Future

  • N-grams
  • CQL-lite
  • Lemma/POS KWIC
  • Annotation-aware Concordance
  • Richer Collocates
  • Export and copy workflows

Known alpha limits

These are not hidden future promises. They are the boundaries of the current public alpha.

Concordance and Collocates: functional alpha features, not the final workflow design.

Indexing: alpha.8 still uses scan and cached paths. The positional index is not included yet.

Queries: there is no CQL, no N-grams, no lemma/POS KWIC, and no annotation-aware Concordance yet.

Hosting: CorpusWright is local-first. It does not provide remote corpus hosting.

Packaging: Windows builds may still show unsigned-app warnings.

CorpusWright is an open, local-first corpus linguistics workbench, currently in public alpha (v0.1.0-alpha.8). View the source on GitHub
